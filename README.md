## VaultReco

**VaultReco** is a terminal-based system designed for lecturer and student to manage and monitor student attendance.

The main purpose of VaultReco is to help student to keep track of their attendance percentage and determine whether they are in risk of being barred.

**Functionality:**
--
- Calculate the current attendance percentage.
- Attendance calculate based on the current week and class time


**System Requirement**
-- 
Python 3.9.6 or above\
***Note:*** VaultReco runs directly in the terminal.
